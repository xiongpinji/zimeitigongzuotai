# Goal

交付可安装、可验证的本地自媒体工作台：四平台同平台多账号持久登录与可恢复批量发布，独立剪辑台，直播录屏批量高光切片，授权素材语义匹配和有实质性差异的混剪，受策略约束的 Agent 全流程自动化，以及按账号选择并核验的平台商品挂载。以 [验收矩阵](../roadmap-and-acceptance.md) 的 R1–R6 为完成依据。

# Decisions and assumptions

- **待用户确认**：Lingji Cut 为桌面基座；Easel 仅按需移植 Skills；HotClip 是独立高光进程候选且有 AGPL 许可门槛；OpenCut-AI 提供语义索引实现参考。详见 [组件选择](../source-selection.md)。
- 四平台优先级并列：抖音、快手、微信视频号、小红书。扩展平台在 R1–R6 后考虑。
- 账号由持有人授权登录；商品挂载资格按平台、账号和商品类型验证。未知或不支持必须显式停在待处理状态。
- “原创”是素材权利清晰和新的叙事表达，不承诺平台原创标签或流量。
- **开发启动门槛**：用户确认本方案及本项目实际百炼 Credits 风险预算后才启动任何执行 Agent。此前只允许文档、Git 和只读环境检查。

# Constraints and guardrails

- Codex 为总指挥；只允许 `claude-bailian=qwen3.8-max` 主实现、`opencode-bailian=bailian-token-plan-personal/deepseek-v4.1-flash` 并行实现、`qwen-code-review=glm-5.3` 只读审查，不自动增加模型或降级路由。
- 两条实现路由只处理隔离文件或工作树，最多 2 个并行写入 Agent；共享接口、Git 集成和最终判定由 Codex 负责。Agent 不自行创建子 Agent、提交、推送、部署或修改凭证。
- 阶段验收按源码/自动化/真实账号/平台最终状态分层；不能以宣传或模拟结果代替真机真号。每个高风险改动先写有意义的失败测试，再实现和独立复核。
- 账号凭证、录屏及素材不入 Git；发布具有授权边界、账号锁、幂等键、未知状态核查和限流退避。不得绕过验证码、权限或平台风控；不得为“伪原创”制作仅改外观的重复视频。
- 第三方组件固定版本、许可证、NOTICE、依赖和安全审查后再导入。AGPL 与产品分发方式未明确前不得复制 HotClip 代码进宽松许可模块。

# Validation strategy

每项工作先制定聚焦测试，并由 Codex 在审查 diff 后独立运行。接口与状态机覆盖边界、取消、超时、进程崩溃、重启、未知结果和重复提交；编辑器覆盖工程重开、预览/导出一致性；高光/混剪覆盖人工评估样本及版权元数据；发布覆盖沙箱和真实账号两个层级。每个平台分别记录登录保持、普通发布、带货资格、商品挂载和最终平台状态。M6 执行长时负载、Windows 打包、安全与许可证检查。

# Completion criteria

R1–R6 的客观场景全部通过，四平台真实账号及合格商品路径的结果被记录；每个 Agent 产出已由 Codex 审查、复测并记录 verdict；第三方许可证可分发、安装迁移和凭证保护检查通过；不存在被宣传为已完成的待验收能力。计划确认或 Agent 退出本身不代表产品完成。
