# P3-1 本地授权素材与语义匹配接线

本项接续 `P3-1` 的纯内存授权闸门。先交付可持久保存、可验证实际媒体字节的本地素材库，再把本机 Ollama 文本 embedding 接到现有 `SemanticSearchPort`，最后由 Electron 主进程通过受限 IPC 向工作台提供显式导入、索引、推荐与人工加入编辑器的操作。所有测试使用合成素材，不登录或发布平台，也不触发打包。旧版 nomic-embed-text 在本机中文对照中将不相关厨房描述排在夜景前，因此索引固定要求多语言 `nomic-embed-text-v2-moe:latest`；模型缺失时拒绝推荐，不自动下载。2026-09-27 首次拉取该模型遇 Ollama registry TLS 握手超时，中文排序质量仍待真实模型复测。

## 数据与权限边界

- 素材文件由用户通过系统对话框选择，主进程复制到 `userData/assets-v1/media/`，按 SHA-256 命名；元数据、画面文字描述、结构化 `RightsGrant` 在 `userData/assets-v1/catalog.json` 原子提交。Renderer 不传任意本地路径，不直接读素材或授权证据文件。
- 素材目录只接受普通非符号链接视频/图片/音频，导入时对已复制文件算哈希并读取时长；恢复时拒绝损坏或版本不兼容的目录，使用前重新检查文件哈希。目录写者只由持有单实例锁的主进程创建。
- `authorizedForAutoUse`、结构化授权平台/地区/商业用途/有效期与证据必须同时通过既有 `asset-rights.ts`；用户填写的授权说明文本不单独放行。撤销自动使用后后续推荐和自动合成不能使用该素材。
- embedding 只发送画面描述、标签和可选转写到固定本地 Ollama loopback；不发送账号、授权证据、权利持有人或素材原始字节。不自动下载模型或访问云端。索引记录绑定素材 SHA、描述哈希和模型 digest；失配、服务不可用或索引缺失返回明确不可用，绝不随机兜底。
- 推荐返回模型分数、匹配标签、来源和授权证据引用；加入编辑器前再次核验文件与授权。文本 embedding 不能证明画面内容与描述一致，视觉 CLIP/多模态索引及真实样本质量仍属后续验收。

## 验收顺序

1. 先写失败测试：文件导入与重启恢复、同 SHA 去重、越权/过期拒绝、媒体篡改拒绝、撤销、目录损坏及并发写者；再实现持久库。
2. 先写失败测试：本地 embedding 响应与维度/NaN 校验、模型 digest/描述哈希失配、余弦排序、未授权 ID 不进入端口；再实现索引与适配。
3. 接入主进程、preload、工作台与编辑器；测试路径注入和伪窗口拒绝、显式索引/推荐、重启恢复、人工导入。以合成 MP4 运行一次实际 Electron 冒烟。
4. Codex 复核 diff，运行聚焦测试、`tsc --noEmit`、源码构建与相关全量测试。记录未验证的视觉匹配、R4 三版合成与平台原创反馈。
