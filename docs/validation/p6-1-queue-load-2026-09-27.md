在 Windows、Node v22.23.3、主库 `963bf84` 上，新增显式运行的 `app/tests/load/durable-queue.load.ts` 和独立 `app/vitest.load.config.ts`。命令：在 `app/` 下执行 `vitest run --config vitest.load.config.ts --reporter=dot`。该测试不进入默认快速回归；`vitest list --filesOnly` 仍列出 376 个默认文件，未包含负载文件。

| 检查 | 实测结果 | 边界 |
| --- | --- | --- |
| 任务规模 | 100 个模拟账号 × 10 个视频版本 = 1000 条独立任务，四个平台各 25 个账号 | 只使用本地引用与假适配器，没有平台登录、上传或远端作品。 |
| 并发预算 | `global=8`、`device=8`、每平台 2、每账号 1；提交执行器实测同时活动峰值为 8，同账号提交无重叠 | 证明本地调度能实际领取 8 个模拟提交，不能视作平台允许 8 路上传。 |
| 完成与持久化 | 1000 次提交、1000 次模拟核验，全部到 `published`，每项只提交 1 次；任务 ID 无重复；关闭本轮后重新打开 store，仍有 1000 条最终态 | 模拟核验直接返回 `published`；本测试没有叠加限流、断电或未知提交。对应故障路径仍须独立验证。 |
| 时间 | 250 轮、167,511 ms，约 5.97 条最终任务/秒 | 这是本机 JSON 持久化和零网络假适配器的观察值，不是承诺吞吐或平台速度。 |
