# 四平台普通视频发布接入核验门槛（2026-09-25）

本页记录当前可见的**官方公开资料**与阶段一工程门槛。它不是接口权限获批、账号测试或平台合规结论；平台页面、权限和速率可能变化，接入前必须重新核对。

| 平台 | 当前查到的官方能力 | 对本项目的实施门槛 |
| --- | --- | --- |
| 抖音 | [创建视频接口](https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/create/create-video)写明 `video.create` 需申请权限及用户授权，创建后仍有审核；代用户创建时，每次调用都须让用户明确感知该操作。[接入方案](https://open.douyin.com/platform/resource/docs/ability/content-management/douyin-publish-solution/)列出授权账号作品与审核状态查询能力。 | 先验证应用获权、账号逐一授权和每次发布的用户可感知交互，再调用官方接口；记录远端作品 ID、审核中与最终状态。现有“活动预授权”纯门控不能单独证明满足逐次感知要求。 |
| 快手 | [快手创建视频官方文档](https://open.kuaishou.com/platformDocs/openAbility/contentManagement/createAVideo)列出 `user_video_publish` scope、发起上传→上传→发布三步；发布接口异步返回 `photo_id`，仍须查询最终状态。 | 先验证应用权限与每个账号的授权 scope；上传成功和返回 `photo_id` 仍需后续状态查询，不能把本地上传调用完成视为已公开发布。 |
| 微信视频号 | 本轮未取得可核对的官方公开普通视频发布 API 文档。 | 保留浏览器/人工接管适配边界；必须用授权账号验证视频号助手实际登录、草稿/提交/最终作品状态。不能由“未查到公开文档”推断平台绝无合作或定向接口。 |
| 小红书 | 本轮未取得可核对的官方公开普通视频笔记发布 API 文档。 | 同样先核对应用/账号资格与官方渠道；浏览器适配器只按真实账号测试和最终状态验收，不把自动化脚本返回当成发布成功。 |

工程执行上，四平台均须把“授权/预检、上传、提交、平台审核、最终公开”分为不同状态。限流或资格不足时降低并发或暂停；未知提交先远端核对，禁止盲目重发。每个平台的同平台多账号可保存数量、同时操作预算和平台风控限制分别实测与记录，不能用本地 worker 数量替代平台许可。

本轮未使用任何真实账号或调用平台发布接口。商品挂载仍只保留请求拒绝与插件端口；商品 ID、账号资格和挂载接口不由普通视频发布资料推断。
