# R3 产品批量高光：SRT 来源收据与本地实测

2026-10-05，Codex 从 `58d672c` 主库继续补齐此前阻断产品 SRT 输入的来源收据。范围是用户显式选择录屏与**同目录、同文件名**的 `.srt`，由主进程在私有 `userData/highlights-v1/subtitles/` 中保存按 SHA-256 命名的字幕快照。未选字幕的录屏仍走原有 HotClip 自动转写路径；本轮没有下载或测试 ASR 模型。

## 实现与停机规则

- 页面只显示所选文件名；路径保留在主进程，必须经系统文件对话框选择。每份 SRT 与已选录屏按目录及文件名配对，不能由渲染进程传入任意磁盘路径。
- 导入前按授权根目录读取 SRT，拒绝目录外文件、符号链接、不同名文件和超过 16 MiB 的输入；读取前后核对文件身份与哈希。快照的文件名就是 SHA-256。已有同名快照若被改动，导入失败而不静默覆盖。
- 排队任务只保存快照路径，不保存字幕正文或 LLM 凭证。相同录屏/SRT 重复导入沿用原任务；SRT 内容变化产生新任务身份。重启后执行前，重新核对私有快照路径、文件类型、大小和内容哈希，失败则记 `source_unavailable`，不会启动 HotClip。
- 该检查是启动前观察，不是子进程打开文件期间的操作系统锁。候选仍只供人工审核，不会自动批准或发布。

复现本地模型联测需先在独立端口 `127.0.0.1:11435` 启动 Ollama，设置 `OLLAMA_MODELS` 指向被忽略的 `data/tools/ollama-models/`、`OLLAMA_CONTEXT_LENGTH=8192`，安装 `qwen3:4b-instruct`；另需独立安装的 HotClip 副本与合成素材都在被忽略的 `data/`。从 `app/` 运行：

```powershell
node ../data/tools/hotclip/node_modules/tsx/dist/cli.mjs scripts/probe-highlight-product-local-win.ts
node scripts/smoke-highlight-queue-win.cjs
```

本轮不包含已授权真实直播录屏及冻结标签的双人盲审、自动语音识别、平台原创判定、真实账号与最终发布结果。HotClip 的 AGPL 分发审查和安装包验收仍是独立闸门。
