## 本次接入的服务

- `app/electron/composition/review.ts` 从三至十二份已完成、哈希核验通过的版本工程读取计划和编码产物。文本使用归一化二元字 Jaccard，来源用同录屏的时间区间并集交并比，画面用有界抽帧 dHash 对比，音频用最多前 30 秒的能量序列对比。画面/音频缺失明确记为不可用；全部分数和标志只供人工复核。
- FFmpeg 取样限定时长、帧数、内存和子进程时间；不落盘原始抽帧或音频。报告只保存计划 ID、输入/输出哈希、配对分数和提示，不保存本机媒体路径。`review-report.json` 有内容哈希；复核决定绑定当前报告、所有版本的已完成状态及来源/输出哈希，改变任何一版即失效。
- `review-decisions.json` 保存五项 1–5 分、否决原因、复核者 ID 和证据哈希。同一版本同一证据的相同 ID 不能重复记票；并发提交串行。达到两个不同 ID 且评分一致，只返回 `ratings_agree`，仍保持 `reviewRequired: true`、`platformOriginality: unverified`。ID 不代表已验证的人类身份；真实双人盲审尚未完成。
