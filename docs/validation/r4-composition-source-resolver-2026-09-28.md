# R4 合成素材解析：离线验证记录

基线：`5f2758d`。新增 `app/electron/composition/source-resolver.ts`，在主进程用人工审核切片收据和已授权的本地素材库解析计划；输入只含计划、收据 ID、平台/地区/商业用途，不接受界面提供的媒体路径。实际文件路径只出现在解析结果中，供后续主进程时间线和渲染服务使用。

## 已验证行为

- 计划必须通过生产文档契约，含结构化编辑意图、唯一分段顺序及逐段审核切片选择；绝对录屏时间码会映射成审核输出内的相对入点和出点。
- `ReviewedClipExporter.verifiedOutput` 重新校验收据内容哈希和切片输出字节哈希；解析器再核对任务状态、任务产物、高光范围、录屏 ID 与原始文件哈希。异步文件校验后读取最新任务状态。
- `LocalAssetLibrary.verifiedForUsage` 校验素材字节和当前平台/地区/商业用途的结构化授权；解析器读取最新授权记录并保留证据引用。使用时间由主进程时钟端口生成，输入中的旧时间不能让过期授权重新生效。再次调用解析器会重新检查媒体和授权。
- 收据、输出文件或素材字节改变时阻断；不支持的 B-roll 类型、越界时间码、非法平台、任务产物与计划高光范围不一致时阻断。素材记录被删除返回 `asset_unavailable`，与媒体文件被改的 `media_changed` 区分；固定错误码不包含本地内部路径。
