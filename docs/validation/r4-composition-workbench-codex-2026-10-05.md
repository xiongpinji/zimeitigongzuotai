# R4 B3 多版本混剪产品接线：离线源码验证（2026-10-05）

用户当前要求先测试、不打包。本段把前序计划、来源核验、独立时间线、批量渲染、相似度和人工复核接到桌面主进程及工作台；验证只使用合成输入和假模型，没有付费调用、真实账号、真实录屏或平台发布。R4 的真实授权素材审片、双人盲审和外部只读复审仍未完成。

## 产品路径与边界

1. 新“多版本混剪”标签读取当前打开的工程。主进程从受控高光任务、已审核切片收据和授权素材库重建当前来源事实；页面只选择 ID、用途和用户检查过的匿名摘要。未勾选“摘要可发送给当前默认 AI”时不能请求模型。
2. 本地语义素材推荐先通过平台、地区、商业短视频用途的授权筛选，界面只收到推荐素材 ID、分数和固定核验说明，原始授权原因不经过桥接。生成服务在发送摘要前再次校验切片收据和素材授权；模型只见匿名主题、批准的摘录、时间码和匿名素材描述，不见文件路径、账号、Cookie 或授权凭证。假模型测试证明三份合格候选能分别落成可编辑时间线；重复叙事和非法候选由既有计划契约拒绝。
3. 主窗口专用 `composition-v1` 桥只接收当前工程的批次/计划 ID、目标用途及人工评分。生成、打开、渲染、取消、相似度分析和复核记录的路径均由主进程派生；渲染结果剔除本地输出路径。打开某版本后可以返回原批次工程。
4. 审核时新增实时来源守卫：重新从高光任务和素材库核对切片、授权及来源身份；已撤销或变化的输入阻止新的分析和人工评分。评分一致只记录为复核证据，`reviewRequired` 仍为 true，`platformOriginality` 仍为 `unverified`。

## 尚未验收

没有调用当前实际默认 AI 来观察三份候选质量，也没有真实本地索引素材的匹配样本；隔离桌面只验证空工程入口与主进程桥，未走有素材的生成、编辑、渲染、审核全链路。真实已授权直播录屏、来源授权撤销的实际文件场景、两名独立人工盲审者、平台原创反馈和 GLM 外部只读复审均未做。B3 是源码接线及合成路径证据，R4 产品和整个阶段一仍保持未通过；安全发布队列不能据此直接接收“已原创”标志。
