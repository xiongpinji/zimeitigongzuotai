# R4 三版叙事候选端口：离线验证记录

基线：`2b508a7b6279e35671cacacab48df72a418e55bf`。本轮新增 `app/electron/composition/plan-proposals.ts`，通过可注入生成器取得候选，再由本地契约校验和明显重复闸门筛选。调用方只向生成器传经批准的匿名主题、转写摘录、素材描述、媒体类型和时间码；录屏路径、内容哈希、账号及会话引用不进入简报。

## 可验证行为

- 要求模型至少返回三份候选；生成器不可用、数量不足或格式不合法时停止，不用随机排列补足。
- 候选计划和分段 ID、顺序、时间戳由本地生成；模型不能指定项目路径、ID 或时间戳。每份计划必须有叙事摘要、完整的计划级与逐段编辑意图，且只引用本次批准的高光和素材。
- 同一中心问题加同一批高光属于明显重复；只改封面/BGM 描述、交换顺序或小幅裁剪时间码无法通过。共享高光但中心问题不同会留下人工复核标记；所有返回批次始终 `reviewRequired: true`。
- 生成器修改简报或调用方输入也不能扩大批准来源集合或改写本批时间。批次返回模型标识和提示词版本，后续持久化由版本工程任务负责；模型异常内容不写入错误消息。
