# R4 前置：视频源时间码与剪辑台裁剪的离线验证

范围：在 `de2337449cc23af59fbc342534bc81d1b6d7f828` 基线上修复 Lingji 时间线的视频源入点、裁剪及分割连续性，作为 P3-2 合成计划回写的前置能力。本轮**没有打包、安装、登录真实账号或向平台发布**；源媒体由 FFmpeg 本地生成，验证产物在 Git 忽略的 `app/data/runtime/validation/`。

## 发现和处理

- 原视频图层始终从源文件第 0 帧播放，即使计划保存了非零 `inMs`，实际渲染也会取错画面。图层现在持久保存 `videoData.trimStartMs` 与源时长，预览和 Remotion 导出按帧率换算源入点；旧项目无该字段时仍从 0 开始。
- 左边缘裁剪以前只改变时间线位置和长度，未移动源入点；分割后的右段以前重复播放左段的起始画面。现在裁剪、分割会同步更新视频源入点，并限制编辑不能越过已知源时长。旧时间线在首次裁剪或分割时补齐源信息；音频分割也保持源入点连续。
- 视频图层详情新增“源起点（ms）”，可在保持时间线位置不变时调整源片段。新插入视频图层从已导入素材记录带入源时长；只知道旧图层时长而不知道实际源时长时，编辑范围保守限制在已知范围内。
