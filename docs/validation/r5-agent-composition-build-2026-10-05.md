# R5 智能体触发混剪版本：离线源码验证（2026-10-05）

## 本轮接线

在“智能体分析授权”中单独确认当前工程 30 分钟的 `build_compositions` 权限。授权后，用户在混剪台选已审核导出的高光切片与授权素材、检查给当前 AI 的匿名摘要，并准备一次性任务。生产 MCP 工具 `lingji_production_build_compositions` 不接收路径、摘要、模型或密钥参数，只消费桌面端准备的任务，返回批次与版本 ID。生成的至少三个独立可编辑版本仍需人工复核；工具不渲染、不登录、不发布。

主进程在准备前核对当前工程、授权与可见资源；执行前重新核对，且任务只可消费一次。模型和来源解析完成后、写入前以及每个版本正式提交前再次检查授权和工程。授权切换或撤销会清除准备并使正在运行的任务后续提交失败。版本批次原本就是逐版本提交：如果撤销发生在前一版已经提交后，已提交版本保留待人工检查，后续版本不会继续提交；不能把失败说成整批原子回滚。素材用途和来源由现有混剪解析器继续复核。
