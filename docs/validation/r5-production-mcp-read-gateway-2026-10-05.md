# R5 独立生产 MCP 只读入口：离线协议验证（2026-10-05）

基线 `cadec28`。当前继续按用户要求先测试源码，不打包、不登录真实账号、不发布。本轮为后续九类生产动作建立独立的本地协议入口，并只接入账号草稿列表与账号 × 审核版视频的只读预检；没有开放创建草稿、放行队列、浏览器操控或平台提交工具。

`/production-mcp` 与旧 `/mcp` 使用独立、无对象原型的会话表。每个协议请求在解析消息或复用会话前都要求回环地址、无浏览器 `Origin`、专用 48 位十六进制令牌，并用定长比较核对。专用令牌留在 Git 外的本机受限文件中，不进入端点发现文件、HTTP 响应或日志；令牌文件权限初始化失败时，新入口拒绝访问，旧编辑工具服务仍可启动。新入口不发送跨源允许头；请求体上限为 1 MiB，异常会话 ID 不会命中对象原型。工具处理器只返回安全投影和固定错误码，不返回工程路径、会话引用或原始异常。

先补认证用例时因缺少模块失败；实现后两项边界用例通过。相关七文件回归 **32 项通过、1 项 Windows 环境下跳过**；`npx tsc --noEmit`、`npx electron-vite build`、脚本语法检查均退出 0。真实 Electron + Streamable HTTP 离线探针在隔离 home、隔离 userData 与合成空工程中运行：首次因旧编辑器状态读取早于页面同步而失败，给旧断言增加等待后通过；加入请求体和会话边界后曾出现一次 `ECONNRESET`，无法归因为产品或探针，随后三次运行退出 0，保留该不稳定记录。最终通过证据位于 Git 忽略目录 `data/runtime/validation/r5-mcp-1791167451224/result.json`，包含旧入口 31 个工具、独立入口仅两项只读工具、无/错令牌及浏览器来源拒绝、异常会话 ID 返回 404、超大请求返回 413、账号草稿空列表、未知账号预检固定错误码、页面异常 0、真实用户发现文件元数据不变。探针没有调用录屏/模型/渲染/平台。

这只是 R5 只读入口和传输认证。旧 `/mcp` 仍保留现有编辑工具及原连接方式，未完成旧入口的整体认证迁移；专用令牌也不能替代生产活动授权。后续写动作必须由受信任主进程发行/撤销活动授权，在每次调用及队列事务中重校验项目、动作、账号、时间和配额，并记录可恢复审计。九类工具、全流程自动生产与真实四平台结果仍未验收；GLM 对当前源码的外部只读审查未完成。
