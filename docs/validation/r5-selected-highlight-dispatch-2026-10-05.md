# R5 高光队列定向执行基础：离线验证（2026-10-05）

高光队列此前只有“运行所有待处理任务”入口。为后续按工程授权的智能体执行增加内部定向入口：调度器 `runSelected(taskIds)` 只领取明确列出的待处理任务，并拒绝空列表、超过 100 条、重复、未知、非待处理、稀疏数组和访问器元素；控制器 `runSelected(config, taskIds)` 复用现有模型配置校验、源文件哈希复核、字幕快照复核、中断与产物收据逻辑。原有桌面端“运行全部”行为保留。

先写失败测试，确认两个新入口不存在；实现后两个聚焦文件 24 项通过，完整高光模块 11 文件、177 项通过、2 项跳过。`npx tsc --noEmit` 与源码构建通过。测试使用假 runner 和合成子进程，不调用真实高光模型、不下载模型，也不发布平台；未打包。

这只是内部调度能力，**尚未向 Agent 暴露**。调度器不知道工程归属；开放自动高光前，主进程必须逐项核对任务 ID 与当前工程的私有绑定、源哈希和限时 `detect_highlights` 授权，并从用户明确配置的 HotClip/模型参数取得运行配置。不能把全局队列的 `runQueued()` 直接接到生产 MCP。真实录屏质量、模型效果和 R5 全链路均待验收。
