# R1/R4 → R6 安全账号与审核版视频草稿接线：离线验证（2026-10-05）

基线 `a742e4a`。遵照用户“先不打包，我们先测试”和 Codex 接手剩余源码的指令，本轮只连接本地安全账号、混剪复核证据与持久草稿队列；未登录真实账号、提交平台、调用付费模型或制作安装包。

发布工作台新增安全账号草稿区。一个账号选择一个具体混剪版本，可分别填写标题、描述和标签；同一版本分配给多个账号时，预览明确提示重复内容风险。页面先预览后保存，保存使用当前主进程工程路径，不能由页面传入视频文件路径。主进程重新读取账号 UUID 的有效会话状态、平台一致性、混剪审核结果、输出哈希和素材权利证据，再整批原子写入队列。新草稿状态不被队列 `tick` 领取，重启仍保留；商品请求为非空时维持 `needs_user_action`，不会降级为普通发布。旧发布 runner 的账号仓保持隔离。

通信入口只接受主窗口主 frame，请求异常只返回固定错误码，不向页面回传会话引用、磁盘路径或原始异常。主进程内部的成片引用在日后使用前还需重查当前工程、账号有效状态、平台、输出哈希与审核证据。队列预留的草稿放行方法目前没有 IPC、按钮或自动调用；真实上传适配器仍未接入产品队列。
